# GBIF Alert documentation

GBIF Alert is a [GBIF](https://www.gbif.org)-based early alert system for
invasive species. It monitors a list of species and notifies users by email when
new occurrences appear.

This site is under construction. Pick the guide that matches what you are doing.

## [User guide](user-guide/index.md)

For anyone with an account on a GBIF Alert instance: finding observations,
setting up alerts, defining your own areas, and getting the data out.

## [Operator guide](operator-guide/index.md)

For whoever runs an instance day to day: choosing what the instance tracks,
managing areas, running imports, sending notification emails, and editing site
content.

## [Concepts](concepts.md)

The shared vocabulary both guides use. Start here if a term is unfamiliar.
