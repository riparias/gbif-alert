# User guide

How to use a GBIF Alert site, in three steps:

1. **[Exploring the data](explore.md)**: browse, filter and look at
   observations. No account needed.
2. **Getting alerts**: create an account, define your own areas, and be
   notified by email when new observations match what you follow.
3. **Going further**: the API, and opening the data in GIS software such as
   QGIS.
