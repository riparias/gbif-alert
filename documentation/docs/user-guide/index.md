# User guide

How to use a GBIF Alert site, in three steps:

1. **[Exploring the data](explore.md)**: browse, filter and look at
   observations. No account needed.
2. **[Getting alerts](alerts.md)**: create an account, define your own areas,
   and be notified by email when new observations match what you follow.
3. **[Going further](advanced.md)**: share filtered views, open the
   observations in QGIS, get the original data from GBIF, and use the API.
